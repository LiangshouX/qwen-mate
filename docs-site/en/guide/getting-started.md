# Getting Started

## Open QwenMate

Click the QwenMate icon in the right sidebar of the IDE to open the tool window. The gear icon in the panel header leads to all settings.

## First-use checklist

Before sending your first message:

1. **CLI detection**: the plugin read-only detects the local `qwen` command and points you to settings if it is missing
2. **SDK dependency**: check `Settings → SDK Dependencies`; if it is not installed, follow the [Installation](./installation) guide
3. **Authentication**: run `qwen` in a terminal to log in; the plugin shares the CLI's credentials

## Start a conversation

- Type your request in the input box, press `Enter` to send, `Shift+Enter` for a new line
- Replies stream in with the thinking process displayed as it happens
- You can stop generation at any time

## Build context

| Input | Purpose |
| --- | --- |
| `@filename` | Reference a project file and include its content |
| `#name` | Invoke an agent |
| `!content` | Insert a prompt |
| Image attachment | Paste or drop an image to describe requirements visually |

- **Prompt enhancer**: when enabled, your input is rewritten into a fuller instruction before sending
- **Reasoning effort**: five effort levels are available from the conversation UI, or switch with the `/effort` command in the input box

## Send content from the IDE

Select code or content and send it to the panel from the context menu:

- Editor selection: right-click → send selection (`Ctrl+Alt+K` / `Cmd+Alt+K`)
- Editor quick fix: `Ctrl+Shift+Q` / `Cmd+Shift+Q`
- Editor selection context menu → copy selection reference, then paste it to the AI
- Project view file or editor tab right-click: send file
- Console selection right-click: send selected output
- While running or debugging, output is monitored so you can have the AI analyze failures directly

## Approval and diffs

Before the AI edits files or performs sensitive actions, an approval dialog appears and nothing runs until you confirm. When code changes are involved, review the diff first and accept or reject. To avoid confirming the same action repeatedly, let the dialog remember your choice for the session.

## Tabs and templates

- The panel supports multiple session tabs: create, rename, or detach a window to work in parallel
- Recurring conversation openings can be saved as templates and used to start new sessions

## Session management

The panel keeps a session history with restore, search, export, and favorites. Titles are generated by AI so past sessions are easy to scan.

## Commit AI

In the Git commit panel, generate a commit message with one click, edit it if needed, and commit.

## Keyboard shortcuts

| Action | Windows / Linux | macOS |
| --- | --- | --- |
| Send selection | `Ctrl+Alt+K` | `Cmd+Alt+K` |
| Quick fix | `Ctrl+Shift+Q` | `Cmd+Shift+Q` |
| Send message | `Enter` | `Enter` |
| New line in input | `Shift+Enter` | `Shift+Enter` |
| Copy / cut / paste in panel | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | `Cmd+C` / `Cmd+X` / `Cmd+V` |

On conflicts, search for `QwenMate` in `Settings → Keymap` and rebind.
