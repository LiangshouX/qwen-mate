# 设置与配置参考

点击 QwenMate 面板顶部的齿轮图标进入设置。左侧侧边栏共九个页面，本文逐一说明。

## 基础配置

外观、行为与运行环境的总配置。

- **主题**：深色 / 浅色主题，跟随 IDE 或单独指定
- **颜色**：用户消息背景色、聊天栏颜色，提供预设色板，也可以自定义十六进制颜色，一键恢复默认
- **UI 字体 / 代码字体**：默认跟随 IDE 编辑器字体，也可以指定自定义字体文件
- **DIFF 主题**：四个选项，跟随面板主题、跟随编辑器、浅色、柔和深色
- **语言**：可手动选择，也可跟随 IDE；从未设置过时默认中文
- **行为开关**：流式输出等对话行为的开关，其中托管记忆默认关闭（开启后回合结束后还要等后台记忆任务完成，可能多等数十秒到数分钟）
- **通知**：声音通知（支持自定义提示音）、AskUserQuestion 提问通知等
- **环境**：Node.js 可执行文件路径、工作目录；Node.js 路径为空时插件自动检测

## 供应商管理

两个标签页：

- **模型供应商**：可视化配置 `~/.qwen/settings.json` 中的模型供应商与模型
- **CLI 工具**：只读检测本机 `qwen` 命令行的安装状态与版本，附安装说明入口

### 模型供应商

页面按分组列出 CLI 预置供应商（Alibaba ModelStudio、第三方服务商、自定义接入）、自定义 Provider 桶与独立模型，可以：

- **连接 / 配置 / 删除**：连接预置供应商，配置协议（OpenAI / Anthropic / Gemini 兼容）、Wire API、端点、API Key、模型（可搜索的预置列表或自定义 ID）与高级项（思考、上下文窗口、max_tokens、模态）；删除前二次确认
- **增删改模型**：模型条目覆盖 ModelConfig 全字段（标识、路由与凭据、生成配置、extra_body、自定义请求头），预置桶与独立模型都可逐个编辑
- **API Key 安全**：输入框为密码型、已存密钥永不回显，页面上以状态徽标显示「已配置 / 引用环境变量 / 来自 Shell 环境 / 未设置」，另提供两步确认的「清除密钥」

改动由本机 Node 服务写回**用户级** `~/.qwen/settings.json`，采用与 CLI 相同的 JSONC 格式保持引擎，注释、缩进、换行与 BOM 都不会丢失，写入前校验、失败保留恢复副本。项目级 `settings.json` 若定义了 `modelProviders`，页面顶部会给出覆盖告警，本页只改用户级文件。

登录态仍由 Qwen Code CLI 管理；API Key 则可以在上面的「模型供应商」页直接配置。

## SDK 依赖

Qwen Code SDK 的安装、升级、回退、重装都在这个页面完成，支持离线安装包。

安装不完整、版本回退等操作指引也会出现在这里。

## 用量统计

统计 Qwen Code CLI 写入本机的用量数据：token 消耗、会话、请求、工具调用与代码改动行数。统计维度可切换 全量 / 按项目 / 按会话（按会话时整页展示所选会话的统计，跨天会话才显示趋势线），时间窗口支持今日 / 7 天 / 30 天，附 token 拆分、模型份额、技能调用排行、每日趋势与最近 12 个月的热力图，可手动刷新。Qwen Code 版本过旧（不记录用量数据）时，页面会给出版本提醒。

## MCP 服务器

管理 Model Context Protocol 服务器：

- 内置市场浏览，快速接入常用服务器
- 手动添加、编辑、删除服务器配置
- 查看连接状态与每个服务器提供的工具列表

终端里配置好的 MCP 服务器在这里可以直接看到，配置与 CLI 共享。

## 增强提示词

配置提示词增强规则：开启后发送前自动改写输入。规则支持自定义，改乱了可以一键恢复默认。

## 配置文件关系

| 位置 | 内容 | 谁来改 |
| --- | --- | --- |
| `~/.qwen/settings.json` | 模型、认证、MCP、Skills 等 CLI 配置 | Qwen Code CLI、插件（供应商管理页 / MCP 页）或直接编辑文件 |
| `~/.qwen/` | CLI 会话数据 | CLI 与插件共享 |
| `~/.qwenmate/` | 插件自身数据与 SDK 依赖 | 插件管理 |

对话相关的参数（如推理强度档位）在对话界面调节，不在设置页。

## 注意事项

- 插件与 CLI 的配置、会话完全共享，在终端里配好的内容插件里直接可用
- 供应商与模型的改动由插件写回用户级 `settings.json`，格式与 CLI 一致；登录态仍由 Qwen Code CLI 管理
