# 设置与配置参考

点击 QwenMate 面板顶部的齿轮图标进入设置。左侧侧边栏共九个页面，本文逐一说明。

## 基础配置

外观、行为与运行环境的总配置。

- **主题**：深色 / 浅色主题，跟随 IDE 或单独指定
- **颜色**：用户消息背景色、聊天栏颜色，提供预设色板，也可以自定义十六进制颜色，一键恢复默认
- **UI 字体 / 代码字体**：默认跟随 IDE 编辑器字体，也可以指定自定义字体文件
- **DIFF 主题**：四个选项，跟随面板主题、跟随编辑器、浅色、柔和深色
- **语言**：可手动选择，也可跟随 IDE；从未设置过时默认中文
- **行为开关**：流式输出等对话行为的开关，其中托管记忆默认关闭（开启后回合结束后还要等后台记忆任务完成，可能多等数十秒到数分钟）
- **通知**：声音通知（支持自定义提示音）、AskUserQuestion 提问通知等
- **环境**：Node.js 可执行文件路径、工作目录；Node.js 路径为空时插件自动检测

## 供应商管理

两个标签页：

- **Qwen 配置**：只读展示 `~/.qwen/settings.json` 中的模型列表，标注当前模型与上下文窗口大小
- **CLI 工具**：只读检测本机 `qwen` 命令行的安装状态与版本，附安装说明入口

认证由 Qwen Code CLI 管理，插件不提供修改入口。需要更换模型或认证方式时，修改 `~/.qwen/settings.json`，或在 Qwen Code CLI 中操作，插件会读取同一份配置。

## SDK 依赖

Qwen Code SDK 的安装、升级、回退、重装都在这个页面完成，支持离线安装包。

安装不完整、版本回退等操作指引也会出现在这里。

## 用量统计

统计 Qwen Code CLI 写入本机的用量数据：token 消耗、会话、请求、工具调用与代码改动行数。支持今日 / 7 天 / 30 天三个时间窗口，附 token 拆分、模型份额、技能调用排行、每日趋势与最近 12 个月的热力图，可手动刷新。Qwen Code 版本过旧（不记录用量数据）时，页面会给出版本提醒。

## MCP 服务器

管理 Model Context Protocol 服务器：

- 内置市场浏览，快速接入常用服务器
- 手动添加、编辑、删除服务器配置
- 查看连接状态与每个服务器提供的工具列表

终端里配置好的 MCP 服务器在这里可以直接看到，配置与 CLI 共享。

## 增强提示词

配置提示词增强规则：开启后发送前自动改写输入。规则支持自定义，改乱了可以一键恢复默认。

## Commit AI

生成 Git 提交信息的相关配置。使用入口在 IDE 的提交面板，见[快速上手](./getting-started#commit-ai)。

## Skills

浏览与管理 Qwen Code 技能（Skills），与 CLI 共享同一份技能目录。

## 其他设置

- **输入历史补全**：开关输入历史自动补全，查看、删除历史记录，清理低重要度条目
- 其他杂项设置

## 配置文件关系

| 位置 | 内容 | 谁来改 |
| --- | --- | --- |
| `~/.qwen/settings.json` | 模型、认证、MCP、Skills 等 CLI 配置 | Qwen Code CLI 或直接编辑文件，插件只读 |
| `~/.qwen/` | CLI 会话数据 | CLI 与插件共享 |
| `~/.qwenmate/` | 插件自身数据与 SDK 依赖 | 插件管理 |

对话相关的参数（如推理强度档位）在对话界面调节，不在设置页。

## 注意事项

- 插件与 CLI 的配置、会话完全共享，在终端里配好的内容插件里直接可用
- 认证只能通过 Qwen Code CLI 管理，这是刻意的只读设计，避免两处配置打架
