# 快速上手

## 打开 QwenMate

点击 IDE 右侧边栏的 QwenMate 图标，打开工具窗口。面板顶部有设置（齿轮）图标，所有配置都在那里；标题栏另有刷新图标（白屏时重建界面）和「查阅文档」图标（打开帮助文档站）。

## 首次使用检查

发送消息前，先确认三件事：

1. **CLI 检测**：插件会只读检测本机 `qwen` 命令行的安装状态，位置在 `设置 → 供应商管理 → CLI 工具`；未检测到时按提示在终端安装
2. **SDK 依赖**：设置 → `SDK 依赖` 中状态正常，未安装时按[安装指南](./installation)完成安装
3. **认证**：在终端运行 `qwen` 完成登录，插件与 CLI 共享认证

## 发起对话

- 在输入框输入需求，`Enter` 发送，`Shift+Enter` 换行
- 回复以流式输出，思考过程（thinking）会同步展示
- 生成过程中可随时停止
- AI 生成期间发送的消息不会打断当前任务，而是自动排队，当前任务结束后依次发出；`Ctrl+Q` 是对齐 CLI 的显式排队快捷键。队列里的消息可以单条放回输入框编辑，也可以一键全部放回
- 输入区头部显示上下文用量占比，任务进行中会实时更新

## 组织上下文

| 输入 | 作用 |
| --- | --- |
| `@文件名` | 引用项目文件，把文件内容作为上下文 |
| `#名称` | 唤起智能体（agent） |
| `!内容` | 插入提示词 |
| 图片附件 | 粘贴或拖入图片，可视化描述需求 |

- **提示词增强**：开启后，发送前自动改写你的输入，让指令更完整
- **推理强度**：对话界面提供 5 档推理强度可调，也可以在输入框用 `/effort` 命令切换
- **托管记忆**：输入框配置弹层提供开关，默认关闭；开启后回合结束后还要等后台记忆任务完成，可能多等数十秒到数分钟

## 从 IDE 发送内容

选中代码或内容后，通过右键菜单直接发送到面板：

- 编辑器选中代码：右键 → 发送选中代码（`Ctrl+Alt+K` / `Cmd+Alt+K`）
- 编辑器快速修复：`Ctrl+Shift+Q` / `Cmd+Shift+Q`
- 编辑器选区右键 → 复制选区引用，把引用粘贴给 AI
- 项目视图文件右键、编辑器标签页右键：发送文件
- 控制台选中输出右键：发送选中内容
- 运行 / 调试时，输出会被监听，出错时可直接让 AI 分析

## 审批与 Diff

AI 修改文件、执行敏感操作前会弹出审批对话框，确认后才执行。涉及代码变更时可以先查看 Diff，再决定接受或拒绝。不想逐次确认时，可以在审批对话框中选择对本会话记住选择。

## 多标签与模板

- 面板支持多个会话标签：新建、重命名、分离窗口并行工作
- 常用的对话开头可以保存为模板，之后从模板新建会话

## 会话管理

面板提供历史会话列表，支持恢复、搜索、导出和收藏；会话标题由 AI 自动生成，方便回看时快速定位。

## Commit AI

在 Git 提交面板中，可以一键生成提交信息，生成结果可编辑后再提交。

## 常用快捷键

| 操作 | Windows / Linux | macOS |
| --- | --- | --- |
| 发送选中代码 | `Ctrl+Alt+K` | `Cmd+Alt+K` |
| 快速修复 | `Ctrl+Shift+Q` | `Cmd+Shift+Q` |
| 发送消息 | `Enter` | `Enter` |
| 输入框换行 | `Shift+Enter` | `Shift+Enter` |
| 排队发送（对齐 CLI） | `Ctrl+Q` | `Ctrl+Q` |
| 面板内复制 / 剪切 / 粘贴 | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | `Cmd+C` / `Cmd+X` / `Cmd+V` |

快捷键冲突时，在 `设置 → 键位映射` 中搜索 `QwenMate` 重新绑定。
