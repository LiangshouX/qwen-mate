# FAQ 与故障排查

## 安装与启动

### 侧边栏找不到 QwenMate 工具窗口？

通过 `视图 → 工具窗口 → QwenMate` 打开；仍不见的话，确认插件已在 `设置 → 插件` 中启用，然后重启 IDE。

### 提示找不到 qwen CLI / CLI 检测失败？

插件只读检测本机 `qwen` 命令，不会自动安装 CLI。

1. 在终端运行 `qwen --version`，确认命令可用
2. 如果终端里也没有，先安装 Qwen Code 命令行，安装方式见 [Qwen Code 官方文档](https://qwenlm.github.io/qwen-code-docs/zh/users/overview)
3. IDE 是从登录 shell 启动才能继承 PATH，装好后重启 IDE 再检测

### 认证失败或提示未登录？

登录态由 Qwen Code CLI 管理。在终端运行 `qwen`，按引导完成登录后回到插件重试。API Key 可以在 `设置 → 供应商管理 → 模型供应商` 页配置，登录 / 登出仍走 CLI。

### 模型在哪里改？

在 `设置 → 供应商管理 → 模型供应商` 页直接操作：连接供应商、增删模型、配置 API Key 都在这里完成，改动写回用户级 `~/.qwen/settings.json`（格式与 CLI 一致）。也可以修改该文件或在 Qwen Code CLI 中切换，插件读取同一份配置。

### 打开后聊天界面完全空白（白屏）？

界面空白说明网页视图没有渲染出来，插件进程本身仍在运行。按顺序处理：

1. 点工具窗口标题栏的刷新图标（或 `⋮` 菜单里的「重新启动界面」）重建界面，不需要重启 IDE。标题栏是 IDE 原生控件，白屏时仍可点击
2. 启动阶段会自动重试两次；两次都失败时约 30 秒后界面会显示「界面启动失败」面板，点面板上的按钮同样可以重建
3. 以上都无效再重启 IDE。重启后仍复现的，多半是环境问题，按下面的方式取证反馈

需要反馈时，提供 `idea.log`（菜单 `帮助 → 在资源管理器中显示日志`）中包含 `WebviewWatchdog` 或 `fallback bridge injection` 的日志片段。注入日志里的 `url=<empty>` 表示页面从未加载成功，`url=` 有值则表示页面已加载但没有渲染出来，两者原因不同；一并附上同目录的 `jcef_chromium_*.log` 更有帮助。

## SDK 依赖问题

### SDK 安装不完整，提示缺少 native 二进制文件？

这是淘宝 npm 镜像源的已知问题，镜像未完整同步平台相关文件导致，不是插件缺陷。两种处理方式：

- 方案一：临时切换 npm 官方源后，在 `SDK 依赖` 页面重装，完成后再切回淘宝源
- 方案二：在 `SDK 依赖` 页面把 SDK 回退到 v0.2.112 或更早版本，切换后重启 IDE

淘宝源同步完成后此问题会自动消失。

### 启动报 spawn EBUSY，子进程启动失败？

通常由 Node.js 版本不兼容或 SDK 安装不完整引起：

1. 检查 Node.js 版本，建议 Node 20 或 22，用户反馈 Node 24 上报错较多
2. 切换到 npm 官方源（淘宝源可能没有最新版本），在 `SDK 依赖` 页面重装最新 SDK

### 恢复历史会话时报「会话恢复失败」？

会话线程恢复请求被服务端拒绝，一般是会话已过期或服务端不支持该操作。重新发起新会话，或选择更早的其他历史会话恢复。

## 使用问题

### macOS 上聊天面板滚动卡顿？

macOS（尤其 Retina 屏）上可禁用 GPU 加速：打开 `帮助 → 编辑自定义 VM 选项`，加入：

```
-Dide.browser.jcef.gpu.disable=true
```

然后重启 IDE。

### AI 每次改文件都弹审批，可以关掉吗？

审批是敏感操作的保护机制，执行文件修改前必须经过确认。如果不想每次确认，可以在审批对话框中选择对本会话记住该选择，之后同类操作不再逐次弹窗。

### 快捷键和别的插件冲突？

在 `设置 → 键位映射` 中搜索 `QwenMate`，为对应动作重新绑定快捷键。

### 内网环境（完全无外网）怎么安装？

1. 在有网机器上下载插件 ZIP，通过 `从磁盘安装插件…` 安装
2. 使用 Qwen SDK 离线包，在终端运行 `install-offline.bat` / `install-offline.sh` 安装到 `~/.qwenmate/dependencies/qwen-sdk/`
3. 认证按公司内网的 Qwen 服务接入方式配置

### 插件的数据存在哪里？

- `~/.qwenmate/`：插件自身数据与 SDK 依赖
- `~/.qwen/`：Qwen Code CLI 的配置与会话

排查问题需要清理数据时，退出 IDE 后删除对应目录即可，注意删除前备份会话记录。
